# Disney+ Desktop

把 Disney+ 網頁版（disneyplus.com）包成 Windows 桌面程式，並加入：

- Netflix 風格的字幕樣式
- 播放速度
- 21:9 螢幕的寬螢幕填滿
- 電腦支援時，以 1080p 和 4K HDR 播放

所有功能都整合在播放器原本的「**設定**」選單裡，不需要安裝任何瀏覽器擴充功能。

> **可用性只用台灣的 Disney+ 帳號驗證過。** Disney+ 在不同國家的服務、方案和內容都不同，其他地區的帳號在播放、高畫質和畫質標示上可能有差異。

本程式不是 Disney 製作，也與 Disney 無關，是透過官方網站播放你自己訂閱的 Disney+。Disney+ 及其標誌為 Disney 的商標。

## 開始使用

1. 從 [Releases](https://github.com/trajis-tech/disney-plus-enhanced/releases) 下載 `DisneyPlus-Setup.exe` 並執行（也可以自行編譯，見[自行編譯](#自行編譯)）。安裝精靈會跟著 Windows 顯示語言。
   - 檔案沒有數位簽章，第一次執行時 Windows SmartScreen 可能跳出警告，請點「**其他資訊 → 仍要執行**」。
   - 預設只安裝給目前的使用者（`%LOCALAPPDATA%\Programs\Disney+ Desktop`），不需要系統管理員權限；第一個對話框可以改成安裝給所有使用者。
   - 會在開始功能表建立「**Disney+**」捷徑，也可以選擇建立桌面捷徑。
   - 在 Windows「設定 → 應用程式」裡的名稱是「**Disney+ Desktop**」，從這裡解除安裝。
2. 第一次開啟請登入 Disney+，之後會記住登入狀態。
3. 播放影片時，點播放器右下角的「**設定（⚙）**」，選單內容如下：

| 項目 | 說明 |
| --- | --- |
| 字幕 | Disney+ 原生的字幕語言選擇 |
| 音訊選項 | Disney+ 原生的音訊語言選擇 |
| 字幕樣式 | Disney+ 原本的頁面，內容換成本程式的選項（見下方） |
| 寬螢幕填滿 | 點一下切換開／關 |
| 高畫質 | 點一下依序切換 1080p → 4K HDR → 關閉 |

### 快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl+Shift+S` | 直接打開「設定 → 字幕樣式」（再按一次關閉） |
| `Ctrl+Shift+W` | 切換寬螢幕填滿 |
| `F11` | 全螢幕 |
| `F5` | 重新整理 |
| `F1` | 說明：快捷鍵，以及適用時的畫質提示 |

在標題列按右鍵（或按 `Alt+空白鍵`）的選單裡也有這些功能。不論開啟哪個頁面，標題列一律顯示「Disney+」。

`DisneyPlus.exe` 是同一個程式的單一可攜版，可以從 Releases 下載，自行編譯時在 `dist\DisneyPlus.exe`。它不需要安裝就能執行，並共用同一份登入資料。

## 版本與更新

標題列選單（在標題列按右鍵，或按 `Alt+空白鍵`）有三個項目：

| 項目 | 說明 |
| --- | --- |
| 關於 Disney+ Desktop | 顯示版本號和專案網頁連結 |
| 檢查更新… | 立即檢查 |
| 自動檢查更新 | 預設開啟，點一下切換開／關 |

按 `F1` 的說明和 `__dpd.qualityInfo()` 也會顯示版本號。

- **自動檢查：** 程式啟動 20 秒後檢查一次，之後每 24 小時檢查一次。正在播放影片時不會打擾，等離開播放器後才詢問。
- **安裝版：** 按「**立即更新**」後，程式會：
  1. 下載新的安裝程式。
  2. 用 GitHub 為發行版公布的 SHA-256 雜湊值核對檔案。
  3. 以原本的安裝模式靜默安裝。
  4. 重新開啟程式。

  只安裝給目前使用者時不需要系統管理員權限；安裝給所有使用者時，Windows 會跳出 UAC 要求權限。
- **可攜版：** 會改成提供下載頁面的連結。
- **來源：** 更新只來自本儲存庫的發行版。
- **從 1.0.0 升級：** 1.0.0 還沒有更新功能，請手動安裝一次 1.0.1，之後的版本就會自動更新。

## 字幕樣式

這一頁沿用 Disney+ 原版「字幕樣式」頁的外觀和元件，只把選項換掉。每次調整都會立即套用到畫面上的字幕、顯示在預覽中，並自動儲存。

| 區塊 | 項目 | 選項（**粗體**為預設） |
| --- | --- | --- |
| 文字 | 大小 | 超小／小／**中**／大／超大，平均分配（視窗高度的 3.0%、3.75%、4.5%、5.25%、6.0%），會隨視窗縮放 |
| 文字 | 字型 | **黑體**／細黑體／楷體／明體／思源黑體／思源宋體 |
| 文字 | 顏色 | **白色**／淺黃／金黃／淺藍／淺綠／黑色 |
| 文字 | 效果 | **柔和陰影**／投影／描邊／無 |
| 背景 | 不透明度 | **無**／半透明／不透明 |
| 位置 | 高度 | **低**／中／高 |

- **預設值：** 仿照 Netflix，白色黑體字、柔和陰影、沒有底色，字幕貼近畫面底部。
- **位置：** 字幕貼齊 Disney+ 字幕區域的底部。控制列隱藏時字幕會降到接近畫面底部，控制列出現時則跟著上移避開。Disney+ 刻意放在畫面上方的字幕（例如畫面文字的翻譯）維持在上方：控制列隱藏時貼近畫面頂端，控制列出現時則移到頂部控制列下方。
- **思源黑體／思源宋體：** 這兩套是 Noto 字型家族，涵蓋所有語言的文字。程式只使用電腦上已安裝的版本，不會從網路下載；沒有安裝時會改用系統字型。
- **對比：** 陰影、描邊和背景底色會自動和文字顏色形成對比：淺色文字用黑色效果，黑色文字則用白色。
- **只有一套設定：** Disney+ 原本的字幕樣式設定已完全取代，不會出現兩套設定互相衝突。

## 高畫質（1080p／4K HDR）

「設定」選單裡的「**高畫質**」，點一下依序切換 **1080p（預設）→ 4K HDR → 關閉**。選單會顯示狀態和實際播放的解析度，例如「4K HDR · 2160p」或「1080p · 無 HDCP · 480p」。

| 檔位 | 做法 | 需要的條件 |
| --- | --- | --- |
| 1080p | 改用 Disney+ 播放器內建的 Edge PlayReady 設定（H.264） | 顯示卡支援硬體 DRM（PlayReady SL3000）；畫面輸出有 HDCP 1.4 |
| 4K HDR | 同 1080p，再開放 HEVC／HDR10，並向 Disney+ 要求 HEVC HDR10 串流 | 上述條件加上 HDCP 2.2 和 HEVC 10-bit 解碼；Disney+ 方案包含 4K，且片子本身有 4K 版本；要看到真正的 HDR，Windows 須開啟 HDR |
| 關閉 | Disney+ 原本的播放方式（Widevine，最高 720p） | — |

- **自動判斷：** 程式啟動時會先檢查條件，不符合就維持一般播放。例如透過遠端桌面操作時沒有 HDCP。
- **自動降級：** 遇到硬體 DRM 輸出失敗、授權或金鑰被拒、播放 40 秒內畫面沒有前進，或授權不斷重來，就會自動降一級（4K HDR → 1080p → 一般）並提示。同一個分頁不會重試。
- **1080p 失敗時不重新整理：** Disney+ 播放器會自己改用軟體 DRM，以 720p 從原位置接著播，程式會配合它的降級。如果硬要再求 1080p，授權會被拒，畫面會出現 Disney+「錯誤代碼 83」。
- **只用硬體 DRM：** Disney+ 對軟體 PlayReady 最高只給 720p，所以 1080p 以上一定要硬體 DRM。
- **記住失敗：** 硬體 DRM 輸出失敗每次都會一樣，所以程式會記住這張顯示卡失敗過，7 天內直接用一般畫質播放，不會每次開啟都重試。排除原因後（例如更新驅動程式），在選單點一次「**高畫質**」即可立刻重試。
- **不破解 DRM：** 程式不解密，也不偽造 HDCP 或授權。能播什麼，由 Disney+ 的授權伺服器和電腦的 DRM 決定。
- **截圖：** 使用硬體 DRM 播放時，截圖畫面會是黑的。

測試用的台灣帳號實例：螢幕接 Intel UHD Graphics 770（HDR 螢幕、HDCP 2.2）時，《復仇者聯盟：無限之戰》以 3840×2160 HEVC HDR10 播放。

### 內建提示

電腦達不到所選的畫質時，程式會說明原因和解決方法。提示會在每次開啟後第一次播放影片時，出現在視窗正中央並自動關閉；按 `F1` 的說明裡也看得到。

| 情況 | 提示內容 |
| --- | --- |
| 顯示卡沒有通過 Disney+ 的輸出保護（`0x8004CD22`） | NVIDIA RTX 50 系列驅動程式的已知問題。CPU 有內顯的話，把螢幕改接到主機板的影像輸出；更新驅動程式後，再點一次「高畫質」 |
| 沒有硬體 PlayReady | 顯示卡不支援硬體 DRM，最高只能 720p |
| 沒有 HDCP | 遠端桌面、擷取卡、切換器和部分擴充座會造成這個情況，請把螢幕直接接到電腦 |
| 4K HDR 但沒有 HDCP 2.2 | 請使用支援 HDCP 2.2 的螢幕、線材和輸出埠（期間以 1080p 播放） |
| 4K HDR 但不能解 HEVC 10-bit | 更新顯示卡驅動程式，或從 Microsoft Store 安裝「HEVC 視訊延伸模組」 |
| 4K HDR 但螢幕沒有 HDR | 開啟 Windows 的 HDR：設定 → 系統 → 顯示器 → 使用 HDR |

### 硬體 DRM 輸出失敗（`0x8004CD22`）與 NVIDIA RTX 50

`0x8004CD22` 是 `DRM_E_TEE_OUTPUT_PROTECTION_REQUIREMENTS_NOT_MET`，意思是畫面輸出達不到授權要求的保護。問題在顯示卡驅動這一端，程式沒辦法繞過。

- **NVIDIA RTX 50 系列：** 已知的驅動程式問題。帶有「類比輸出限制」的硬體 PlayReady 授權，在 NVIDIA 的所有輸出上都會失敗，而 Disney+ 的 1080p 授權正好有這項限制。同樣的授權從 Intel 內顯輸出就能播。NVIDIA 已在內部追蹤，目前還沒有修正版驅動。
- **暫時的解法：** CPU 有內顯的話，把螢幕改接到主機板的影像輸出。已實測：RTX 5070 Ti 的電腦改接 Intel UHD Graphics 770 後，1080p 和 4K HDR 都能播。遊戲仍可以用 NVIDIA 顯示卡跑：到「設定 → 系統 → 顯示器 → 圖形」把遊戲設成「高效能」。
- **其他情況可以試試：** 更新顯示卡驅動程式、拔掉其他螢幕並關閉虛擬顯示器、螢幕直接接電腦（不經過擴充座、KVM 或擷取卡）。

### 畫質標示

Disney+ 網頁版不管片子有什麼版本，片名下方最多只標「HD」。程式會改成依這台電腦實際能播的畫質標示：

| 情況 | 標示（片名下方和「簡介」分頁） |
| --- | --- |
| 「高畫質」設為 4K HDR，且這台電腦能播（條件符合、沒有降級過） | 有 4K 版本的片子標「4K 超高畫質」；HDR 螢幕再加標「HDR10」 |
| 其他情況 | 「高畫質」（HD） |

- **拿掉的標示：** Dolby Vision、3D、Dolby Atmos、DTS:X 和 5.1 網頁版播放器都播不出來（4K 播的是 HDR10，音訊是 AAC 立體聲），所以這些標示會拿掉。
- **何時更新：** 切換「高畫質」或發生降級後，重新開啟頁面標示就會更新。

### 診斷

播放影片時按 `F12`，打開「主控台」執行：

```js
copy(JSON.stringify(__dpd.qualityInfo(), null, 1))
```

結果會複製到剪貼簿，內容包括：

- 程式版本（`appVersion`）
- 硬體 PlayReady 和 HDCP 的狀態
- 目前使用的檔位，以及播放器是否已自行降低畫質（`playerCappedQuality`）
- 各檔位失敗的原因（`failures`），以及記住的硬體失敗（`hardwareDrmBlocked`）
- 目前的提示（`tip`）和介面語言（`language`）
- 實際播放的解析度
- 顯示卡、螢幕解析度、是否為 HDR 螢幕、能否解 HEVC

## 播放速度

速度按鈕（儀表圖示）在播放器右下角「設定（⚙）」的左邊，外觀和檔位參考 Netflix。

- 點按鈕會跳出「播放速度」面板，共五個檔位：0.5x／0.75x／1x（正常）／1.25x／1.5x。
- 可用滑鼠點選，或用方向鍵切換。
- 調整速度時聲音不會變調，字幕也會跟著影片同步。
- 在播放器內會一直維持這個速度，下一集也一樣；離開播放器後恢復 1x。
- 一次只顯示一個面板：打開速度面板時，Disney+ 的設定選單會自動收起。

## 寬螢幕填滿

依照視窗比例計算放大倍率，讓 2.39:1 的電影填滿 21:9 螢幕、去除左右黑邊，畫面上下會略為裁切。

- 在 16:9 螢幕上不會放大。
- 最多只放大到 2.39:1 的裁切範圍。
- 只作用在播放中的影片，瀏覽頁的預告片不受影響。
- 換集時會自動套用。

## 系統需求

- Windows 10/11 x64。
- Microsoft Edge WebView2 Runtime。Windows 11 已內建；缺少時程式會提示下載頁面。
- .NET 已打包在 exe 內，不需另外安裝。

## 資料位置

`%LOCALAPPDATA%\DisneyPlusDesktop\`

- `WebView2\`：登入資料和 Cookie。
- `settings.json`：視窗位置、字幕樣式、寬螢幕填滿和畫質設定。

解除安裝時會保留這個資料夾，重新安裝不必再登入。想登出或重設，關閉程式後刪除這個資料夾即可。設定環境變數 `DPD_DATA_DIR` 可以改用其他資料夾（例如可攜用途）。

### 實作說明

- **字幕：** 樣式套用在 Disney+ 自己的字幕元素上：`<timed-text-override-region>` 的 shadow root 內，`.hive-subtitle-renderer-cue-positioning-box` 底下的 `span.hive-subtitle-renderer-cue`。
- **設定選單：** 沿用 Disney+ 的 `<settings-modal>` 對話框。
  - 「字幕樣式」頁（`<caption-settings-view>`）的原始表單會被隱藏，改放入以 Disney+ 原生元件組成的表單：`caption-preview`、`captions-font-size`、`styled-radio-buttons`、`picker-dots` 和 `snap-slider`。
  - 主選單（`<main-settings-view>`）另外加入「寬螢幕填滿」和「高畫質」項目。
- **控制列：** 閒置時 Disney+ 會把整個控制列移除。`Ctrl+Shift+S` 會先模擬滑鼠移動把它叫回來，再打開設定。
- **播放速度按鈕：** Disney+ 播放器上蓋著一層透明的「點擊暫停」圖層（`<pointer-actions>`），只有登記過的控制項位置能讓點擊穿過去。
  - 速度按鈕用和 Disney+ 自己按鈕相同的方式登記：對最近的 `data-ui-ptr-scope` 元素送出 `ui-ptr-exclude-register`。
  - 滑鼠停在速度面板上時，程式會把這些操作轉告播放器，控制列和面板就不會在使用中途收起。
- **高畫質：** 程式包裝 Disney+ 播放 SDK 的 `createPlaybackSession`：
  - 傳入 SDK 自己的設定覆寫（PlayReady recommendation 流程、播放清單篩選和解析度）。
  - 宣告這台電腦實際能解碼的格式。
  - 4K HDR 時向 Disney+ 要求 HEVC HDR10 播放情境。
  - SDK 自行降低畫質時，就不再調整它的請求。
- **畫質標示：** 在頁面讀取前，改寫 Disney+ explore API 回應裡的 `audioVisual.flags` 清單。
